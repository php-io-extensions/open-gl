# Agent guidance — php-io-extensions/opengl

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1.** Global functions and constants keep their C names, including the lower-case `k` of `kCGLPFAAccelerated`. No defaults, no composites. The translations are only the ones in [data](.okf/architecture/data.md): a pointer plus a count is one list, an out-parameter is by reference, an info log is a string, `const void *` is `string|int|null`, a destination `void *` is `?int`, and a buffer offset is an `int`.
3. **Constants are the C constants**, registered with `@cvalue` from the platform header. Not class constants. `EGL_DEFAULT_DISPLAY` is the literal `0` because the C macro is a pointer cast.
4. **Handles** (`CGLPixelFormatObj`, `CGLContextObj`, `EGLDisplay`, `EGLConfig`, `EGLContext`, `EGLSurface`, `GLsync`) are `final`, not constructable, not cloneable, not serializable, with `pointer(): int` and `static fromPointer(int $pointer): static`. One identity table per thread. Dropping the last PHP reference does not destroy the native object. `CGLReleaseContext`, `CGLDestroyPixelFormat`, `eglDestroyContext`, `eglDestroySurface`, and `glDeleteSync` release the handle. `EGLDisplay` and `EGLConfig` are never released. Releasing the current context clears it first.
5. **Every `gl*` body opens with `OPENGL_REQUIRE_CONTEXT()`.** No current context throws `Error` "`name(): no current OpenGL context`".
6. **Addresses.** A string must hold what GL will read, sized from the pixel-store state or from the buffer size. A short string and address 0 throw `ValueError`. Address 0 is a valid `glReadPixels` offset only while a pixel-pack buffer is bound. Any other address is trusted.
7. **Attribute lists end with their terminator** (`0` or `EGL_NONE`). A list that does not is a `ValueError` before CGL or EGL reads it. `eglGetPlatformDisplay` widens the list to `EGLAttrib`.
8. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, and commit both. Never hand-edit `*_arginfo.h`. `gl.stub.php` is both platforms; `CGL.stub.php` is macOS; `EGL.stub.php` is Linux. One `.c` includes `gl_arginfo.h` and registers the functions (`src/gl_state.c`). A later `.c` defines more of those functions and does not register them again.
9. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts`. On the Pi, copy the tree and `./install-debian-trixie.sh`. Pest at `-d memory_limit=128M` on `php84`, `zhp`, and Pi `php`. Gate a commit on the suite's exit code.
10. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`.
11. **Version** is `PHP_OPENGL_VERSION` in `php_opengl.h`: 0.10.0. `os-families` are `linux` and `darwin`.
