# Agent guidance — php-io-extensions/opengl

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1.** Global functions and constants keep their C names, including the lower-case `k` of `kCGLPFAAccelerated`. No defaults, no composites. The translations are only the ones in [data](.okf/architecture/data.md): a list GL takes with a count keeps the count as its own parameter, an out-parameter is by reference (`glGen*`, the info logs), `const void *` is `string|int|null`, a destination `void *` is `?int`, a buffer offset is an `int`, a C int converts as C converts it, `GLboolean`/`EGLBoolean` are `bool`.
3. **Constants are the C constants**, registered with `@cvalue` from the platform header. Not class constants. A C macro that is a pointer cast (`EGL_DEFAULT_DISPLAY`) is not bound; PHP passes `null` or `0`.
4. **Handles** (`CGLPixelFormatObj`, `CGLContextObj`, `EGLDisplay`, `EGLConfig`, `EGLContext`, `EGLSurface`, `GLsync`) are `final`, private `__construct`, not cloneable, not serializable, `pointer(): int` (0 once released), `static fromPointer(int $pointer): ?static` (null for 0). One identity table per thread. Dropping the last PHP reference does not destroy the native object. `CGLReleaseContext`, `CGLDestroyPixelFormat`, `eglDestroyContext`, `eglDestroySurface`, and `glDeleteSync` release the handle. A released handle goes to the toolkit as NULL. Releasing the current context makes no extra call.
5. **Refusals are the sites in `bindings.json` only**, each with a probe in `tests/Probes` (`--enable-opengl-probes`, env `OPENGL_PROBE_OFF=<site>`): no current context (macOS; `OPENGL_REQUIRE_CONTEXT()` opens every `gl*` body), a CGL attribute list without its 0, a string shorter than GL reads, address 0 where GL reads it, a count past its list, `wl_egl_window` 0. Anything else goes to the toolkit.
6. **Addresses.** A string is sized from the buffer size, or from the GL 4.1 / ES 3.0 pixel tables and the unpack state. A format/type pair outside the tables goes to GL. Address 0 is NULL where GL takes NULL, an offset while a pixel buffer is bound. Any other address is trusted.
7. **EGL attribute lists go to EGL as given.** `eglGetPlatformDisplay` takes full `EGLAttrib` values.
8. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, and commit both. Never hand-edit `*_arginfo.h`. `gl.stub.php` is both platforms; `CGL.stub.php` is macOS; `EGL.stub.php` is Linux. One `.c` includes `gl_arginfo.h` and registers the functions (`src/gl_state.c`). A later `.c` defines more of those functions and does not register them again.
9. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts`. On the Pi, copy the tree and `./install-debian-trixie.sh`. Pest at `-d memory_limit=128M` on `php84`, `zhp`, and Pi `php`. Gate a commit on the suite's exit code.
10. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`.
11. **Version** is `PHP_OPENGL_VERSION` in `php_opengl.h`: 0.11.1. `os-families` are `linux` and `darwin`.
